# Bybit Open Interest Fetcher

Automated pipeline for fetching historical Open Interest data from Bybit V5 API.

---

### Features

- Fetches historical OI data via Bybit V5 API
- Automatic pagination for large datasets
- Retry logic with exponential backoff
- Rate limiting to respect API quotas
- CSV export with automatic naming
- Support for multiple intervals and categories

---

### Installation

```bash
git clone https://github.com/Zettnq/Bybit-Open-Interest-Fetcher.git
cd Bybit-Open-Interest-Fetcher
pip install -r requirements.txt
```
